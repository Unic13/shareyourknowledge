How it works
Two simple paths — pick the one that fits you
Learn For students
  1. 1
    Pick a subject
    No account needed — browse straight in from the home page.
  2. 2
    Read the chapter
    Concepts, formulas, examples, videos, and the SQL playground where relevant.
  3. 3
    Practice questions
    Answer MCQs, MSQs, and numeric questions with instant explanations.
  4. 4
    Leave feedback
    Rate the subject and tell contributors what to improve.
Create For editors & admins
  1. 1
    Sign in
    Editors, admins, and super admins each get access scoped to their role.
  2. 2
    Get assigned a subject
    Editors only see and edit the subjects an admin has mapped to them.
  3. 3
    Build or import content
    Use the chapter editor directly, or download the template and upload a filled-in JSON file.
  4. 4
    Save — it's live
    Every save is logged, so changes are always traceable back to who made them.
